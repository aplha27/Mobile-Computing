Foundational Literature & Borrowed Innovations

How our two-level architecture synthesizes Sensor2Text, SensorChat, DrHouse, and JARVIS

Sensor2Text Representation Learning

Multimodal Sensor Encoding

The deployed classifier consumes existing ExtraSensory feature rows. The separate 25 Hz chart is synthesized for illustration and is not classifier input.

What we borrowed: Sensor encoder concept, multimodal feature projection, evaluation across unseen test users.
SensorChat Architecture

Three-Stage QA Pipeline

Separates QA into: (1) Question Decomposition, (2) Sensor Data Query, and (3) Grounded Answer Assembly. Replaces raw sensor token passing with compact temporal evidence retrieval.

What we borrowed: Staged evidence retrieval and deterministic query operations over aligned ExtraSensory rows.
DrHouse Evidence & Safety

Confidence & Truthful Rejection

Uses observed coarse place labels, but rejects exact GPS coordinates, addresses, food, heart rate, and conversations. Missing context is reported as unknown.

What we borrowed: Calibrated confidence intervals, evidence-first reasoning, 100% truthful rejection of unsupported domains.
JARVIS Planning & Execution

Deterministic Query Planning

A rule-based planner produces structured JSON plans, while deterministic code executes arithmetic, context intersections, place dwell, and observed transitions.

What we borrowed: JSON intermediate representation, mathematical computation outside LLM, calculation traces.

Two-Level System Architecture
